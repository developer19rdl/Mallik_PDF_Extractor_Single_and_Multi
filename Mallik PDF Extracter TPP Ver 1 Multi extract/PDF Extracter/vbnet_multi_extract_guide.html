VB.NET Multi-Extract Integration Guide

Support Multi-Program TRUMPF Setup Plan PDFs in Form5 with ComboBox Dropdown

1. Summary of Changes Minimal VB.NET Code

When a setup plan PDF contains multiple NC programs (e.g. 18 programs in a 24-page file), the Python server now extracts all individual programs and returns them in a structured dictionary. This enables the VB.NET Form to:

1. Populate ComboBox

Fills a dropdown with all NC program names (e.g. VIHANG_Gaur_3MMHR_1, _3, etc.) and auto-selects the first one.

2. Direct 1:1 Binding

Selecting any program from the ComboBox instantly fills all 8 textboxes with 100% clean, pre-sanitized values.

3. Zero Regex Headaches

No more fragile ExtractWord() or manual string replacements like .Replace("Process", "")!

4. Single & Multi Compatible

Works seamlessly for both single-sheet plans (1 item in dropdown) and multi-sheet plans (18+ items in dropdown).

4. Exact VB.NET Code Changes 3 Easy Steps

Step 1: Declare Class-Level Variable

At the top of Form5 (inside Public Class Form5), add a variable to hold the returned programs:

Form5.vb — Class Declarations VB.NET 
' Stores the dictionary of all programs from the uploaded PDF
Private pdfPrograms As JObject

Step 2: Update UploadPdf() Method

Replace the single regex extraction block with this dropdown population logic:

Form5.vb — Inside UploadPdf(base64String As String) VB.NET 
Using response As WebResponse = request.GetResponse()
    Using responseStream As Stream = response.GetResponseStream()
        Using reader As New StreamReader(responseStream)
            Dim responseFromServer As String = reader.ReadToEnd()
            Dim jsonResponse As JObject = JObject.Parse(responseFromServer)

            ' Multi-program response handling
            If jsonResponse.ContainsKey("programs") Then
                pdfPrograms = CType(jsonResponse("programs"), JObject)

                ' 1. Clear and populate ComboBox with all program names
                ComboBoxProgramCode.Items.Clear()
                For Each prop In pdfPrograms.Properties()
                    ComboBoxProgramCode.Items.Add(prop.Name)
                Next

                ' 2. Auto-select first program (triggers SelectedIndexChanged)
                If ComboBoxProgramCode.Items.Count > 0 Then
                    ComboBoxProgramCode.SelectedIndex = 0
                    MessageBox.Show("Extracted " & ComboBoxProgramCode.Items.Count.ToString() & " NC Programs from PDF!")
                End If
            ElseIf jsonResponse.ContainsKey("csv") Then
                ' Fallback for legacy single-program response if needed
                MessageBox.Show("Single program extracted.")
            Else
                MessageBox.Show("No data found in the server response.")
            End If
        End Using
    End Using
End Using

Step 3: Add ComboBox SelectedIndexChanged Event

When the user changes the program in the dropdown, this event immediately populates the Form controls:

Form5.vb — Event Handler VB.NET 
Private Sub ComboBoxProgramCode_SelectedIndexChanged(sender As Object, e As EventArgs) Handles ComboBoxProgramCode.SelectedIndexChanged
    If pdfPrograms Is Nothing OrElse ComboBoxProgramCode.SelectedIndex = -1 Then Return

    Dim programName As String = ComboBoxProgramCode.SelectedItem.ToString()
    Dim p As JToken = pdfPrograms(programName)
    If p Is Nothing Then Return

    ' 1. Program Code Textbox (TextBox10 or Label)
    TextBox10.Text = programName

    ' 2. Direct 1:1 Clean Assignment into Controls
    TextBox21.Text = p("Machine Name").ToString()
    TextBox16.Text = p("Material Name").ToString()
    TextBox22.Text = p("Thickness").ToString()
    TextBox24.Text = p("Raw Material Weight").ToString()
    TextBox26.Text = p("Process Quantity").ToString()
    TextBox27.Text = p("Laser Material Name").ToString()
    TextBox25.Text = p("Process Length").ToString()
    TextBox18.Text = p("Material Size").ToString()
End Sub

6. Upload Nesting (Save to MySQL) Button10_Click

When the user clicks "Upload Nesting" (Button10), the code will seamlessly insert the currently selected NC Program details because all the TextBoxes (TextBox21, TextBox16, TextBox22, etc.) are already populated with the exact values for that program!

Note: If the user wants to upload all 18 programs into the database at once instead of one by one, a simple loop over pdfPrograms.Properties() can execute the INSERT query for all programs in a single click!
7. Blank Material Validation & Pop-up Handling Automated Warning

If an uploaded PDF has Material left blank by the CAD/CAM operator, the Python server detects it and returns:

  • has_missing_material: true (at the top level)
  • warnings: ["Material Name is blank in PDF for program '...'"]
  • Inside each program: is_material_blank: true and "Material Name": ""

VB.NET Code to Show Warning Pop-up and Highlight TextBox

Form5.vb — In ComboBoxProgramCode_SelectedIndexChanged VB.NET 
' Check if Material is blank in the PDF for the selected program
Dim isMaterialBlank As Boolean = False
If p("is_material_blank") IsNot Nothing AndAlso CBool(p("is_material_blank")) Then
    isMaterialBlank = True
ElseIf String.IsNullOrWhiteSpace(p("Material Name").ToString()) Then
    isMaterialBlank = True
End If

If isMaterialBlank Then
    TextBox16.Text = ""
    TextBox16.BackColor = Color.LightPink ' Visually warn user
    MessageBox.Show(
        "⚠️ Warning: Material is blank in the PDF for program '" & programName & "'." & vbCrLf & vbCrLf &
        "Please manually enter or select the Material Name in TextBox16 before proceeding.",
        "Missing Material",
        MessageBoxButtons.OK,
        MessageBoxIcon.Warning
    )
    TextBox16.Focus()
Else
    TextBox16.Text = p("Material Name").ToString()
    TextBox16.BackColor = Color.White
End If
